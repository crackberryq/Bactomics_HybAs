# HybAs 10.0.0a8 development update

With polishing and BUSCO enabled, the research report measures the retained draft and each executed polishing state. The trajectory section links native per-stage Prodigal and BUSCO evidence, paired MUMmer alignments, CDS overlaps, and machine-readable measurements. Local vectors use the previous protein mean. Geometric distances use the initial mean. Read alignments, where retained, refer to the Polypolish input. Existing runs keep their recorded workflow revision.

A separate retrospective analysis can use the same script and the updated QC environment. Supply the original polishing execution receipt, the same prepared BUSCO lineage directory, and a fresh output directory. Open index.html in the new directory. This requires the original stage FASTAs at the paths recorded in the receipt.
