# HybAs AWARE 9.0.2 — Alpha

Optional identification review now lets researchers run through Kraken before
selecting a target. The run emits an early HTML/JSON report and exits cleanly.
Bactologix can save a choice or record a manual/AWARE decision and continue the
same run, reusing matching classification outputs. Original settings and evidence
remain recorded; changed inputs, database identity, source, or evidence block reuse.

Requires Bactologix with identification-review support. Automatic end-to-end runs
remain the default. Illumina-only, ONT-only and hybrid inputs are supported; this
regular AWARE release does not add the separate AWARE+ reconstruction proposal.
