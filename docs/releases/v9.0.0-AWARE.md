# HybAs 9.0.0-AWARE — release notes

**Release candidate source:** `HybAs_v9.0.0-AWARE`, original commit `9477fd3b6578e23a84d6524e1c89e65e01590f03` (2026-10-19).

This file documents the already implemented v9.0 software changes; it does not assert that a GitHub Release or tag has been published.

## Changes from v8.8

- Platform-aware polishing: Illumina-only Polypolish, hybrid Racon → Medaka → Polypolish, and ONT-only Racon → Medaka under `tripolish`.
- Validated taxid and isolate identifiers, lane pairing, and FASTQ preflight.
- Configurable assembly and SPAdes memory budgets; Kraken scheduling reservations.
- Executed/skipped-stage provenance, final FASTA source and checksums, durable logs, and improved restart behavior.
- QUAST/MultiQC reporting and dependency fixes; frozen AWARE default-policy compatibility tests.

## Qualification boundaries

GitHub Actions regression and environment checks have passed for the original source commit. Workflow tests use mocked bioinformatics executables. Real-tool end-to-end qualification and comparative assembly accuracy are **not** established by these tests. Scientific AWARE controller validation and the separate historical validation bundle are not reproduced here.
