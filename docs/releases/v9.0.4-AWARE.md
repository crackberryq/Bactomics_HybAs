# HybAs 9.0.4-AWARE

This alpha patch preserves generated outputs before reruns and retries, retains failed jobs and generated mapping/read intermediates, and enables supported native retention switches. Existing stage and final paths remain unchanged. See [retention locations and limits](../OUTPUT_RETENTION.md).

Install/update through the checked Bactologix source or the `hybas-v9.0.4-AWARE` prerelease. Keep existing output directories; previous products are archived before a scheduled replacement. Retention consumes more storage and does not recover previously deleted files. No scientific thresholds, input selection or polishing rounds change.

Validation includes real Snakemake storage/failure/retry tests and synthetic workflow regression tests. This is a storage-integrity update, not scientific validation or a beta designation.
