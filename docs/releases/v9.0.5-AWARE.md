# HybAs 9.0.5-AWARE

Fix the retention startup guard for Conda `snakemake-minimal` installations whose distribution metadata reports `0.0.0` while the executable correctly reports Snakemake 9.6.2. The verified runtime module version is authoritative; unknown runtimes and concrete conflicting versions still fail closed. New run software records use the runtime version, so the packaging placeholder is not exported as the Snakemake version.

Retention from 9.0.4 remains enabled. No analysis, filtering or polishing parameters change. Release publication now also requires tests in the native Conda controller, including output replacement, failure/retry preservation and a synthetic workflow's recorded version.

This patch cannot rewrite historical run evidence or establish scientific validation.
